🔑 Google Cloud Access Token

You can use an Application Default Credentials (ADC) access token generated from the Google Cloud SDK (gcloud) as an alternative to signing in.

Run this command in your terminal to generate an access token:
gcloud auth application-default print-access-token
Tokens typically begin with ya29. and expire after one hour. Requires authorization via gcloud auth application-default login.
